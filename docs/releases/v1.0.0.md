## Findings and limits

[Full findings](../FINDINGS.md) retain all 54 cases. No lost query was restored within 60 minutes. Nominal stop-closure benefits are 584/782/782 capped seconds across 100 fixed queries, using hypothetical duties; +5/+10 minute running-time stress removes the modeled benefit. These are not passenger savings or an operational fleet recommendation. Independent routing scope and access disagreements remain in [reference validation](../REFERENCE_VALIDATION.md).

Attribution, source changes, independent branding and simulation labels follow the reviewed Translink correspondence and public terms. Sender headers were not authenticated. OSM-derived walking data is available separately under ODbL; raw collection history, credentials and private correspondence are not published. The demo needs no local backend; custom experiments and collection run locally.
