## Expected output

Provide CLI preparation, bounded date execution, report/export and verification.
Use portable data-dir/config/output options, resumable immutable per-cell results
with exact input/code hashes. Run directly through the existing pure engine;
no infrastructure dependency is needed for this additive batch experiment.
Keep canonical scenario/candidate/requests and snapshot hashes with every run.
Reuse versioned analysis normalization/persistence if possible without changing
old selection-version claims; new wrapper records staggered selection version.
Do not overwrite the existing experiments catalog or 54 old run files.

Build the simple frequency policy independently of the engine's affected-bus
heuristic: count unique full source bus trips of the paired patterns departing
in the closure interval, rank nominally and freeze ranking for stresses. Dispatch
feasible duties of the first-ranked pair up to budget at fixed times. If a whole
pair is infeasible under stress, continue to the next nominal ranked pair and
record why. Report no action, simple frequency policy and best evaluated search.
Keep no-action among alternatives; optimizers may spend zero and nulls are valid.

Derive full/impacted/control paired metrics from actual route arrays. Saved
capped seconds = disrupted minus recovered total, improved_count compares those
same paired query costs, zero-cost efficiency is null. Record primary cohort
identity before policies and retain unchanged across stress. Persist actual
calculation elapsed times separately from model outputs.

Export compact case-study JSON with all public confirmation/replication dates,
four nominal budgets and two added two-hour stress rows per date. Include source
provenance/quality, role, cutoff, protocol/config hashes and a fixed journey
example for each budget. Export machine-readable complete metrics/control rows.
Produce offline reproduction inputs without raw archive publication; a verifier
must recompute all selected results and detect altered inputs/metrics. Root
handles public pack review and publication.
